# Games Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Gérer les jeux et le cycle de vie de leur image locale depuis Filament.

**Architecture:** SaveGame valide les données et coordonne PostgreSQL et GameImages.
GameObserver supprime les anciennes images après commit. Les pages Filament
utilisent le service et conservent les téléchargements temporaires jusqu'à validation.

**Tech Stack:** Laravel 13, Filament 5, PHP 8.4 GD/EXIF, PostgreSQL, PHPUnit.

**Spec:** `docs/superpowers/specs/2026-11-14-games-design.md`

## Global Constraints

- Réutiliser le checkout courant, branche `codex/game-filament`.
- Image optionnelle, WebP local ou SVG conservé ; nom et slug éditables.
- JPEG/PNG/WebP ≤ 5 Mio et 4096 × 4096 pixels ; qualité WebP 85.
- Tests uniquement dans `gamestackr_testing`.

## Review Focus

- Retrait sans sauvegarde : aucun fichier persistant supprimé.
- Échec SQL, stockage ou transaction externe : ancien fichier conservé.
- Noms identiques, Unicode, très longs : aucune collision ou traversée de chemin.
- Suppression groupée et enregistrement concurrent : pas d'image d'un autre jeu supprimée.
- Fichier corrompu, faux type MIME, transparence et orientation JPEG.
